Connect Google
First-time setup
  1. Go to console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable Google Calendar API.
  3. OAuth consent screen → External → add yourself as a test user.
  4. Credentials → Create OAuth client ID → Web application.
  5. Authorised redirect URI: http://localhost:3000/oauth/google/callback
  6. Paste the client ID + secret into .env in the project root.
  7. Restart the server, then hit Connect Google.

Shortcuts

  • ⌘KSearch every to do
  • ⌘ZUndo
  • ⇧⌘ZRedo
  • ⌘NNew task on selected day
  • ⌘⏎Save task
  • ⇧⌘⏎Log — mark done and save
  • EscClose
  • ⌥← / ⌥→Previous / next week
  • ⌥TJump to today
  • ⌘ASelect all visible blocks
  • ⌫Delete the selection
  • TabMove between blocks — then ⏎ edit, D done, ⌫ delete
  • Drag the top edge of a To Do block (or the bottom edge of a Done block) to change its hours. Right-click any block for the full menu. Drag on empty canvas to rubber-band select several, then right-click to act on all of them.
